# What's new in Twitch Space 2.4.3

- **Your saved things survive a reinstall.** Twitch Space keeps a copy of your quick phrases, highlight words, chatter notes, pinned emotes and channels, starred rewards, streaks, bookmarks and markers inside the Twitch page itself. Remove the extension and load it again (from any folder) and it takes them back the first time Twitch loads. The toolbar pop-up also has **Back up** and **Restore**, which save the same copy to a file and read it back, for moving to another browser or computer. (Coming from 2.4.2 or earlier there's no copy yet, so update in the same folder once, as the guide shows; after that you're covered.)
- **Much lighter on busy pages.** Every feature used to watch the whole page on its own and run on every single change, chat lines included. Now there's one watcher, and each feature checks in a few times a second at most. The streak flame's search for Twitch's own streak pop-up no longer reads every bit of text on the page. Long streams with busy chat should stay smooth instead of needing a refresh.
- **Back to the quality-of-life features.** Streamer Buddy System (the handshake button, the side panel hub and chat flagging) is no longer part of Twitch Space; it lives on as its own project. The side panel and handsome-tom.github.io permissions are gone with it.
- Everything else is as in 2.4.2: player, chat box, your name in chat, watch streaks and Streak Saver, channel points, chatter notes, account switcher, pinned channels, split screen, Clear all notifications, bookmarks and VOD markers.
